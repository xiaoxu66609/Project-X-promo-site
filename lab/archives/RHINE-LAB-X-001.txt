试卷星 Project-X 是大连市第五中学信息化部做的校内阅卷和学情系统，主干 README 的公开版本是 v2.7.1。这一页是三维档案终端：四十份档案写的是主仓库已经公开的事实，场景和开场动画还是原来的。进入系统 https://dl5zx.cn/ ，源码 https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X 。开场字样是 PROJECT X。教师和学生用浏览器，扫描走 Windows 端。
